# Accessibility (A11Y) Summary

This shortened reference captures the accessibility improvements implemented for AirBrB. All work targets **WCAG 2.1 Level AA** and was implemented independently.

---

## Principles
- **Perceivable**: Descriptive text, strong contrast, semantic layout.
- **Operable**: Keyboard-first navigation, focus management, escape routes.
- **Understandable**: Clear labels, inline error guidance, consistent UI.
- **Robust**: Radix primitives, ARIA attributes, semantic HTML compatible with assistive tech.

---

## Highlights

### Radix UI Foundation
- Dialog, Dropdown Menu, Select, Tooltip, and Label primitives supply ARIA roles, focus trapping, keyboard shortcuts, and screen-reader announcements.
- Files: `frontend/src/components/ui/*.tsx`, `frontend/src/components/NotificationPanel.tsx`.

### Keyboard & Focus
- Global `focus-visible` rings across buttons, inputs, dialogs (2 px high-contrast outlines).
- All flows (auth, booking, publishing) are keyboard operable; Enter submits forms, Escape closes dialogs, modals trap focus.
- Files: UI primitives, `pages/Login.tsx`, `pages/Register.tsx`, `components/listing/*Dialog.tsx`.

### Screen Reader Support
- `sr-only` text for icon buttons (theme toggle, notifications, dialog close) and ARIA labels on rating stars (`aria-label="Click to see all … reviews"`).
- Semantic buttons, labeled inputs, descriptive `alt` text on thumbnails, titled iframes.
- Files: `components/theme-toggle.tsx`, `components/NotificationPanel.tsx`, `components/listing/RatingDisplay.tsx`, `components/listing/ListingThumbnail.tsx`.

### Forms & Feedback
- Every input has a `<Label htmlFor>` pair plus required indicators; `autoComplete` attributes reduce typing.
- Errors surface via Radix `Alert` components (descriptive text, accessible role); disabled states include opacity + cursor changes.
- Files: `pages/Login.tsx`, `pages/Register.tsx`, `components/listing/*FormSection.tsx`, `components/listing/FormAlerts.tsx`.

### Visual & Responsive Accessibility
- OKLCH color palette ensures ≥4.5:1 contrast in light/dark themes; icons never rely on color alone (badges show text too).
- Responsive typography/layouts keep content readable at 200 % zoom and on 400 px-wide screens.
- Files: `src/style/globals.css`, `components/ui/button.tsx`, `components/ui/input.tsx`.

### Notifications & Status
- Notification badge uses color + numeric count; unread entries show bold text, background tint, and left border for redundancy.
- Polling pipeline documented for future `aria-live` regions.
- Files: `components/NotificationPanel.tsx`, `components/notification/NotificationItem.tsx`.

## Testing
- Keyboard-only walkthrough for auth/listing/booking flows.
- VoiceOver spot checks (navigation, dialogs, alerts).
- Lighthouse + axe scans for contrast/landmarks.
- Manual 200 % zoom and mobile viewport verification.

## Summary
AirBrB now offers accessible foundations: Radix-based primitives, reliable keyboard flows, clear focus states, descriptive labels, strong contrast, and structured feedback. These improvements aid screen-reader users, keyboard-only users, people with low vision, and anyone who benefits from predictable interfaces. Future work will expand with live-region announcements, reduced-motion support, and skip navigation for even stronger accessibility.
